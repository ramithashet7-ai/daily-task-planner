# Daily Task Planner

A simple and responsive web application for managing daily tasks.

## Features

- Add new tasks
- Set task priority
- Set a task date
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Filter tasks by All, Pending, and Completed
- Detect overdue tasks
- Clear all tasks
- Task data is saved using LocalStorage
- Responsive design for desktop and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- LocalStorage

## How to Use

1. Enter a task in the input field.
2. Select a priority.
3. Select a date.
4. Click **Add Task**.
5. Use the available buttons to complete, edit, or delete tasks.
6. Use the filters to view All, Pending, or Completed tasks.
